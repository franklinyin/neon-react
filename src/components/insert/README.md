# Insert Components

This folder contains components for inserting musical elements.

## Structure

- `PrimitiveElements.tsx` - Component for primitive elements (punctum, virga, diamond, etc.)
- `GroupingElements.tsx` - Component for grouping elements (pes, clivis, etc.)
- `SystemElements.tsx` - Component for system elements (staff)
- `InsertButton.tsx` - Reusable button component for insert elements

## Images

Images should be placed in `public/assets/img/` and referenced as `/assets/img/filename.png`
